首次连接：准备 Google 客户端文件
  1. 在 Google Cloud 控制台创建项目并启用 Gmail API。
  2. 配置 OAuth 同意屏幕；测试模式下把自己的邮箱加入测试用户。

  4. 按下方路径放置文件，或启动时用 --credentials 指定文件，再点击“连接 Gmail”。
